# MCP status

The public AsenT1 edition is a self-contained Claude Skill loaded directly from this GitHub repository.

**An AsenT1 MCP server is not required for direct use in Claude Managed Agents.**

Do not configure placeholder tools such as `asent1_status`, `asent1_director_design`, or `asent1_compile_clip` for this public edition. Claude follows the workflow in:

```text
.claude/skills/asent1-video-production/SKILL.md
```

A future hosted AsenT1 service could add MCP tools as a separate product feature, but that is not part of the current public Skill and is not needed for its use.
